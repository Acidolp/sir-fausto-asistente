# Asistente IA Sir Fausto LP

## Qué hace
- Chat natural, incluyendo saludos.
- Usa la base de productos y reglas comerciales.
- Precios únicamente desde la lista suministrada.
- Disponibilidad siempre como consultar.
- Referencia de catálogo/página.
- CTA hacia Instagram @SirFausto.lp.

## Ejecutar
1. Instalar Python 3.11+.
2. `pip install -r requirements.txt`
3. Configurar la variable de entorno `OPENAI_API_KEY` en el servidor (NO ponerla dentro de index.html).
4. `python server.py`
5. Abrir `http://localhost:8000`

Para publicarlo, se puede adaptar este proyecto a un hosting con Python. La clave debe quedar como variable secreta del servidor.
